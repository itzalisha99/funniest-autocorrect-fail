A make.fun bounty entry. The program writes one autocorrect fail — a single line under 200 characters — to `/output/entry.txt`.

## The fail

> Mom, I had children for dinner last night. It was delicious.

Chicken became children, and the sender never noticed — "It was delicious" doubles down like a truly oblivious texter.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 199 characters, not only whitespace, exactly one line.
